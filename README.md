# Dungeon Blitz Talent Calculator

Static mirror of the archived Dungeon Blitz Talent Calculator from:

https://web.archive.org/web/20171211125607/http://dungeonblitzcalc.eu5.net/

Most page assets were recovered from Wayback Machine captures of the original
site and its Photobucket image host. The only talent data JSON available in the
archive lookup was `talents/shadowstalker.json`, so the mirrored calculator
defaults to Rogue / Shadowstalker.
